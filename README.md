# Smart Hospital & Blood Bank Management System

A full-stack Smart Hospital & Blood Bank Management System developed with **React, Flask, MySQL, and SQLAlchemy**. The system provides secure hospital administration, patient management, appointment scheduling, blood inventory tracking, emergency blood requests, and donor management through a modern healthcare dashboard.

## Features

### Hospital Management

* Secure admin authentication
* Patient registration and profile management
* Doctor management
* Appointment scheduling
* Dashboard with hospital KPIs
* Blood inventory overview

### Smart Blood Bank

* Blood inventory management
* Blood component tracking
* Emergency blood requests
* Blood stock status monitoring
* Blood issue and request workflow
* Donor registration and login portal

### Emergency Blood Network

* Create emergency blood requests
* Priority-based request handling
* Hospital blood request coordination
* Request status tracking
* Blood availability monitoring
